# 톡펫

단톡방 모두가 함께 키우는 펫. 밥 주고, 놀아 주고, 씻기고, 똥 치우며 키우면 돌본 방식에 따라 다른 모습으로 자라요.

- 웹 연습판: https://mhyoo-games.github.io/talkpet/ (여러 사람인 척 말해 보고 시간을 빨리 감아 볼 수 있어요)
- 카카오톡 단톡방: 집 PC에서 봇 부계정으로 돌려요 (아래)

만든 사람: 심심풀이

## 게임

| | |
|---|---|
| 알 | 처음 보는 방에서 누가 명령(`/도움말` 등)을 말하면 알이 생겨요. 대화를 10번 나누고 30분이 지나면 깨어나요 (아무도 말이 없어도 6시간이면 깨어남) |
| 돌보기 | `/밥` `/놀기`(`/놀기 가위`면 가위바위보) `/씻기` `/치우기` `/재우기` `/깨우기` `/약` `/쓰다듬기`. 이름을 불러도 돼요: "몽글아 밥 먹자", "몽글아 놀자" |
| 보기 | `/상태` `/순위`(누가 잘 돌봤나) `/앨범`(떠난 펫) `/이름 새이름` `/새알` `/도움말` |
| 시간 | 배부름·기분·청결·기운이 시간이 지나면 줄어요. 밥 먹고 2~4시간 뒤 똥, 더럽거나 굶으면 아파요. 대화가 12시간 넘게 없으면 외로워서 기분이 더 빨리 떨어지고, 대화가 오가면 조금씩 기분이 좋아져요 |
| 밤 | 0시~8시에는 저절로 자고(배도 천천히 고픔) 먼저 말을 걸지 않아요. 아침에 인사해요 |
| 자라기 | 아기(깨어남) → 어린이(12시간) → 청소년(2일) → 어른(5일) → 14일에 독립(앨범에 남고 새 알). 청소년이 될 때 가장 많이 받은 돌봄으로 모습이 정해져요: 밥 통통이·놀기 깡총이·대화 재잘이·씻기 반짝이·잠 꾸벅이·방치 삐죽이 |
| 떠나기 | 건강이 0이 되면 편지를 남기고 가출해요 (앨범에 남고 `/새알`로 다시) |
| 먼저 말하기 | 급한 것(배고파요, 똥, 아파요)은 3시간에 한 번까지. 이틀 넘게 조용한 방에는 말을 걸지 않아요 |
| 같은 사람 연속 | 같은 사람이 같은 돌봄을 3분 안에 다시 하면 막아요 (여러 사람이 나눠 돌보게) |

## 구조

- `src/core/` 화면·카톡과 분리한 순수 TS (import에 `.ts` → `node --test`):
  - `pet.ts` 시간 흐름(줄어들기·밤잠·똥·병·자라기·떠나기), `room.ts` 명령 읽기·답(`handle`)·먼저 말하기(`due`), `words.ts` 모습·말, `kakao.ts` 카톡 PC에서 복사한 글 읽기·새 메시지만 고르기.
- `server/main.ts` 서버 (Node 22, 외부 패키지 없음). 방마다 `data/rooms/*.json`.
- `bridge/` Windows 연결 프로그램 (PowerShell, 설치할 것 없음).
- `src/web/` 웹 연습판 (같은 규칙을 브라우저에서, 이 브라우저에만 저장).

## 카카오톡 단톡방에 붙이기 (집 Windows PC)

카카오가 공식으로 열어 둔 방법이 아니라, **봇 전용 카톡 부계정**을 카카오톡 PC에 로그인해 두고 프로그램이 대신 읽고 쓰는 방식이에요. 부계정이 제한될 수 있으니 본 계정으로는 하지 마세요.

1. 서버 켜기: 이 저장소 폴더에서 `.env`에 `BOT_NAME=봇 카톡 이름`을 적고 `docker compose up -d --build` → http://127.0.0.1:8790/api/rooms
2. (권장) Windows에 봇용 사용자 계정을 하나 더 만들고 거기서 3~4를 해요. 연결 프로그램이 클립보드로 채팅을 읽어서, 같은 계정에서 쓰면 복사·붙여넣기와 겹칠 수 있어요. 계정 전환(로그아웃 말고 "사용자 전환")으로 돌아와도 계속 돌아요.
3. 카카오톡 PC에 봇 부계정으로 로그인 → 친구들이 단톡방에 봇 계정을 초대 → 그 채팅방을 **두 번 눌러 따로 열어 두기** (창을 닫으면 그 방은 못 읽어요. 최소화는 괜찮아요)
4. `bridge/start-bridge.cmd`를 두 번 눌러 켜기
5. 단톡방에서 누가 `/도움말`이라고 말하면 알이 생기고 시작해요

## 시험

```
npm test                  # 규칙 시험

URL=http://localhost:8765/ node scripts/smoke.mjs   # dist를 http로 띄운 뒤 화면 확인
```
